# DocIntel AI - Enterprise Frontend

Modern React + TypeScript dashboard for document ingestion, privacy verification, and RAG search.

## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React**
- **Axios**
- **React Router v6**

## Local Setup (Windows)

1. Install Node.js dependencies:
```powershell
npm install
```

2. Configure environment:
```powershell
copy .env.example .env
```
Default: `VITE_API_URL=http://localhost:8000`

3. Start development server:
```powershell
npm run dev
```

4. Build production bundle:
```powershell
npm run build
```
The application will be accessible at `http://localhost:5173`.
